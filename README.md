# Simple Calculator

A basic Python calculator that performs:

- Addition
- Subtraction
- Multiplication
- Division

## Requirements

- Python 3.x

## How to Run

1. Save the script as `calculator.py`
2. Open a terminal
3. Run:

   python calculator.py

## Example

Enter first number: 10
Enter second number: 5

Select Operation:
1. Add
2. Subtract
3. Multiply
4. Divide

Enter choice (1-4): 1

Result: 15.0

## Features

- User-friendly menu
- Handles division by zero
- Easy to extend with more operations
